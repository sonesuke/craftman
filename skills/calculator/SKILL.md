# Calculator

Evaluates a mathematical expression containing numbers and the operators `+`, `-`, `*`, `/` and parentheses.

## Parameters

- **expression** (string, required): The mathematical expression to evaluate. Example: `"2 + 3 * 4"`

## Examples

| Expression | Result |
|---|---|
| `1 + 1` | `2` |
| `2 * (3 + 4)` | `14` |
| `100 / 4 - 5` | `20` |
